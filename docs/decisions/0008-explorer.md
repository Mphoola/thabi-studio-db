# 0008 — Database explorer

**Status:** accepted · **Date:** 2026-10-15

## Decisions

1. **Shape of the tree per engine.**
   - PostgreSQL: databases → schemas → Tables / Views / Materialized Views /
     Foreign Tables → objects. A PostgreSQL session can only read the
     database it connected to, so other databases show "This connection is
     using “x”. Switch to “y” to browse it." with **Switch Database**, which
     reconnects the profile to that database for this connection only (the
     saved default doesn't change).
   - MySQL: databases → Tables / Views → objects (a database _is_ a schema).
     `list_schemas` returns `null` to say "no schema level", not "none".
   - SQL Server: databases → schemas → Tables / Views → objects, using
     three-part names (`[db].sys.objects`) so every database the login can
     access is browsable from one session.
   - System schemas are hidden (`pg_*`, `information_schema`; SQL Server
     `sys`, `INFORMATION_SCHEMA`, `guest`, `db_*`).
2. **Lazy loading.** Children load the first time a node expands and stay
   cached until refreshed. Groups are built client-side from one object
   list. The tree resets when the connection changes (new connection id).
   Requests run on the session asynchronously; the UI never blocks.
3. **Metadata SQL is generated by the app**, so values are bind parameters
   and identifiers are quoted per engine (`database/quote.rs`,
   `lib/explorerTree.js`): `"…"` doubling `"`, `` `…` `` doubling `` ` ``,
   `[…]` doubling `]`. Database names in SQL Server three-part names can't be
   parameters, so they are quoted.
4. **Structure.** Columns with type (engine's own spelling), nullability,
   default and primary-key position; indexes with key columns, unique and
   primary flags. Views have `indexes: null` ("don't apply") except on SQL
   Server, where views can be indexed, as opposed to `[]` ("none").
5. **Open Data** is a read-only preview of the first 100 rows
   (`SELECT * … LIMIT 100` / `TOP (100)`), clearly labelled. Editing and
   the full results grid are Phase 7–8.
6. **Errors in the tree.** Permission denied (PG `42501`, MySQL
   `1142/1143`, MSSQL `229/262/916`) has its own message. If the session is
   dead (I/O failure), it is closed and the UI shows "The connection to the
   database was lost" with **Reconnect** instead of stale data. Empty
   schemas say so.
7. **Keyboard.** The tree is an ARIA `tree`: ↑/↓ move, → expands or enters,
   ← collapses or goes to the parent, Return opens. Right-click (or the
   context-menu key) opens Open Data, Show Structure, Copy Name, Copy
   Qualified Name, Refresh and, for PostgreSQL, Switch to This Database.
   ⌘R refreshes the explorer.
8. **Dev-only mock backend.** `?mock` on the Vite URL answers commands with
   sample data so screens can be reviewed in a browser. It is never in
   release bundles.

## Not done

- Cancelling a metadata request in flight (requests are short and bounded;
  query cancellation arrives with Phase 7).
- Functions, procedures, triggers and sequences in the tree.
